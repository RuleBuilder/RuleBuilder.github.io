주의사항

  • 반드시 SmartThings Advanced Web App에서 복사하세요.

  • 조명이 Switch Level 기능을 지원하는지 확인하세요.

※ 입력하신 범위에 맞춰 20단계 제어 수치가 자동 계산됩니다. 조명의 기술 사양에 명시된 색온도 범위를 정확히 입력해야 루틴의 오작동을 막을 수 있습니다.

색온도는 1,000K 이상 20,000K 이하로 입력하고, 최소값은 최대값보다 작아야 합니다.

바람세기 범위

선풍기 사양에 맞는 제어 방식을 고르세요.

5단계 고정 레벨

대부분의 스마트 선풍기에서 지원하는 표준 5단계 매핑 방식입니다.

준비 중

1~100 슬라이더

스마트싱스의 최신 업데이트 기능을 지원할 예정입니다. 1% 단위로 정밀 제어가 가능합니다.

볼륨 범위 설정

%

%

40%를 넘으면 칼맞을 수도 있습니다.

※ 0~100 사이의 값만 입력 가능하며, 최소값은 최대값보다 작아야 합니다.

볼륨은 0 이상 100 이하로 입력하고, 최소값은 최대값보다 작아야 합니다.

°C

온도는 0 이상 40 이하로 입력하고, 최소값은 최대값보다 작아야 합니다.

에어컨 바람세기 범위

에어컨 사양에 맞는 제어 방식을 고르세요.

5단계 (1, 2, 3, 4, MAX)

바람세기를 1단부터 5단까지 지원합니다. 스마트싱스에서 바람세기를 1, 2, 3, 4, MAX로 제어할 수 있습니다.

3단계 (약풍, 강풍, 터보풍)

바람세기를 1단부터 3단까지 지원합니다. 스마트싱스에서 바람세기를 약풍, 강풍, 터보풍으로 제어할 수 있습니다.

컬러 톤(채도) 설정

컬러 범위 및 채도 미리보기 모든 채도

※ 채도를 고정하면 스마트싱스에서 유저가 컬러의 톤을 바꾸더라도 다시 원래의 톤으로 돌아갑니다. 유저가 원하는 컬러 톤을 설정하려면 모든 채도를 고르세요.
